# tools/ —— 阶段一小工具

## analyze_log.py

从训练日志里提取 loss 并做统计。

```bash
python analyze_log.py sample_train.log
```

输出示例：

```
[2.5, 2.1, 1.8, 1.5, 1.2, 2.132, 2.1213, 1.812, 1.5412, 1.2231]
共 10 条
首条： 2.5 末条： 1.2231
最小： 1.2 最大: 2.5
平均： 1.79296
```

用到的技术点：正则提取（`re.compile` + 捕获组）、`argparse` 命令行传参、文件读取、列表统计。

### 日志格式

每行需含 `loss=数字`（例如 `step 0 loss=2.5`），脚本会用正则 `loss=([\d.]+)` 提取数字。
